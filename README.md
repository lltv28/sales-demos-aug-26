# Kodara Sales Demos

Six automatic 16:9 demo loops for Kodara's sales presentation.

## Routes

- `/sales-department/`
- `/self-funding-flywheel/`
- `/ai-brain/`
- `/reinvestment-controls/`
- `/organic-workflow/`
- `/paid-ads-loop/`

## Local development

```bash
npm install
npm run dev
```

All activity and figures are deterministic and illustrative. The demos are generalized for businesses with consultative or educational sales processes.
